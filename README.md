# M. Ismail Tasks Management

تطبيق React عربي لإدارة مهام الضرائب والمحاسبة. يعمل بالكامل في المتصفح ويخزن المهام ومراحل الإنجاز محلياً، مع دعم الإضافة والتعديل والحذف والنسخ والبحث والتصفية واستيراد وتصدير JSON/CSV وتقارير الأداء.

## أوامر التشغيل

| الأمر | الغرض |
| --- | --- |
| `pnpm dev` | تشغيل بيئة التطوير محلياً. |
| `pnpm check` | فحص TypeScript دون إنشاء ملفات بناء. |
| `pnpm build` | إنشاء ملفات الإنتاج داخل `dist/public`. |

## النشر على Netlify

المشروع يحتوي على ملف `netlify.toml` الجاهز. عند ربط مستودع GitHub مع Netlify، ستُقرأ الإعدادات تلقائياً. وإذا أدخلتها يدوياً في Netlify فاستعمل:

| الإعداد | القيمة |
| --- | --- |
| Build command | `pnpm build` |
| Publish directory | `dist/public` |
| Node version | `22` |

> التطبيق ثابت ولا يحتاج مفاتيح سرية أو قاعدة بيانات. تحفظ بيانات كل مستخدم في `localStorage` داخل متصفحه، لذا يفضّل تصدير JSON دورياً كنسخة احتياطية.
